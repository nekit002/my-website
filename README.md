# Learnico — лабораторная №10

Самостоятельная копия ЛР9. Работы 3–9 не изменяются. Сайт использует чистые HTML, CSS и JavaScript; для учебных данных работает локальный сервер Node.js.

## Запуск

В папке `lab-10`:

```powershell
npm ci
npm run server
```

Откройте http://127.0.0.1:3010/ либо страницы `lab-10` через Live Server. Для Live Server локальный API всё равно должен работать на порту 3010. Рабочая база находится вне папки сайта: `%LOCALAPPDATA%\Learnico\lab-10\db.json`. При первом запуске она создаётся из `server/seed.json`, отдельно от базы ЛР9. Администратор создаётся автоматически; адрес и разовый начальный пароль выводятся в терминал. Можно задать `LEARNICO_ADMIN_PASSWORD` перед первым запуском.

## Возможности ЛР10

- Переключение английского и русского языка на всех страницах; активная кнопка языка выделена.
- Светлая и тёмная темы с изменением нескольких изображений на главной странице.
- Язык и тема сохраняются в LocalStorage и восстанавливаются после перехода на другую страницу и обновления.
- После регистрации или входа появляется кнопка профиля. В модальном окне можно просмотреть и изменить личные данные. Пароль никогда не выводится.
- Кнопка сброса настроек возвращает английский язык и светлую тему. Выход удаляет сохранённые данные текущего пользователя и токен.
- Действия с корзиной и избранным читают пользователя из LocalStorage заново при каждом действии; сервер независимо проверяет право доступа. Изменения отображаются без перезагрузки страницы.

Это локальная учебная демонстрация. Используйте вымышленные данные; LocalStorage не подходит для хранения токенов в публичном приложении без дополнительных мер защиты. Настройки привязаны к адресу сайта: страницы на Live Server и на порту 3010 имеют разные хранилища.

## Проверка

```powershell
npm test
node tests/browser.test.cjs
node tests/interactions.test.cjs
node tests/preferences.test.cjs
```

Для браузерных тестов требуется Playwright и Chrome либо Edge. Для Edge задайте `$env:BROWSER_CHANNEL='msedge'`. Браузерные тесты используют временные базы в памяти и порты 3011–3013.
